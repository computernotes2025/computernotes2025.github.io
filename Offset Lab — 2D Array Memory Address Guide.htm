Formula map

One formula.
One swapped priority.

ROW MAJOR01

Skip complete rows, then move across the target row.

B + W [ C(I − Lr) + (J − Lc) ]
KEY MULTIPLIERC = total columns
ROW OFFSETI − Lr
COLUMN OFFSETJ − Lc
COLUMN MAJOR02

Skip complete columns, then move down the target column.

B + W [ R(J − Lc) + (I − Lr) ]
KEY MULTIPLIERR = total rows
COLUMN OFFSETJ − Lc
ROW OFFSETI − Lr

The multiplier tells you what you skip. Row major skips full rows, so multiply by columns. Column major skips full columns, so multiply by rows.
