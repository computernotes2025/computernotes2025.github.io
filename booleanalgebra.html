Question 1 (i)
According to the Principle of Duality, the Boolean equation Q' · 0 + P' · Q' + P' · Q = P' will be equivalent to:
  • (a) Q · 0 + P · Q + P · Q' = P
  • (b) Q' · 1 + P' · Q' + P · Q' = P'
  • (c) (Q' + 1) · (P' + Q') · (P' + Q) = P' ✓
  • (d) (Q' + 0) · (P' + Q') · (P' + Q) = P'

Explanation

According to the Principle of Duality:

  • Change each AND (·) operator to OR (+).
  • Change each OR (+) operator to AND (·).
  • Replace 0 with 1 and 1 with 0.
  • Keep variables and complemented variables unchanged.

Applying these steps to Q' · 0 + P' · Q' + P' · Q = P' yields (Q' + 1) · (P' + Q') · (P' + Q) = P'.

Question 1 (iv)
The Boolean equations a + 1 = 1 and a · 0 = 0 correspond to:
  • (a) Involution Law
  • (b) Law of Identity ✓
  • (c) Distributive Law
  • (d) Law of Complements

Explanation

The Law of Identity (or Properties of 0 and 1) defines operations involving binary constants 0 and 1, such as a + 1 = 1, a · 0 = 0, a + 0 = a, and a · 1 = a.

Question 1 (x)
What is Gray code in Karnaugh map?

Solution

Gray code is a non-weighted binary coding sequence where adjacent values differ by only a single bit (e.g., 00 → 01 → 11 → 10).

In a Karnaugh map (K-Map), Gray code is used to label rows and columns so that physically adjacent cells differ by exactly one variable. This adjacency enables visual grouping and simplification of Boolean expressions.

Question 1 (iii)
Given that P = 0, Q = 1, R = 0, S = 0, write its:
(a) Maxterm
(b) Minterm

Solution

(a) Maxterm: P + Q' + R + S

Rule: Variables valued at 0 are represented in uncomplemented form, while variables valued at 1 are complemented, joined by OR (+).


(b) Minterm: P' · Q · R' · S' (or P'QR'S')

Rule: Variables valued at 1 are represented in uncomplemented form, while variables valued at 0 are complemented, joined by AND (·).

Section A: Objective & Short Answer Questions

Question 1 (i)
Find the complement of the Boolean expression: X = (A · B) + (B' · C)

Solution

Taking complement on both sides:

X' = [(A · B) + (B' · C)]'

Applying De Morgan's First Law (P + Q)' = P' · Q':

X' = (A · B)' · (B' · C)'

Applying De Morgan's Second Law (P · Q)' = P' + Q':

X' = (A' + B') · (B'' + C')

Since B'' = B (Involution Law):

Answer: (A' + B') · (B + C')

Question 1 (iii)
State the dual of the Boolean expression: (1 + Y) · (X + Y) = Y + X
  • (a) (1 · Y) + (X · Y) = Y · X
  • (b) (0 · Y) + (X · Y) = Y · X ✓
  • (c) (0 + Y) · (X + Y) = Y + X
  • (d) (1 · Y) + (X + Y) = Y · X

Explanation

To find the dual of a Boolean expression:

  • Replace + with ·
  • Replace · with +
  • Replace 1 with 0 and 0 with 1

Original: (1 + Y) · (X + Y) = Y + X

Dual: (0 · Y) + (X · Y) = Y · X

Question 1 (iv)
Which law is represented by: A + (B + C) = (A + B) + C?
  • (a) Commutative Law
  • (b) Distributive Law
  • (c) Absorption Law
  • (d) Associative Law ✓

Explanation

The Associative Law states that grouping of variables does not change the result of logical OR or AND operations:

OR Form: A + (B + C) = (A + B) + C

AND Form: A · (B · C) = (A · B) · C

Question 1 (v) [Specimen]
Find the complement of the Boolean function F(A, B) = Σ (0, 1, 2, 3).
  • (a) 1
  • (b) A'B'
  • (c) 0 ✓
  • (d) A + B

Explanation

The Boolean function F(A, B) = Σ (0, 1, 2, 3) contains all possible minterms for 2 variables (22 = 4 minterms).

Thus, the function evaluates to tautology: F(A, B) = 1.

The complement of 1 is 0.
