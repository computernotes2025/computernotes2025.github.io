01 — The Big Picture

Start here before attacking past-paper questions.

🔗 What is a Linked List?

A linked list is a linear data structure in which elements are stored as nodes, not necessarily in continuous memory locations.

🧩 Exam trigger: whenever you see temp = head and temp = temp.next, think “traversal”.

🧠 Key Points to Memorise

  • Node: data + link/reference.
  • Head / start: points to the first node.
  • NULL: marks the end of a singly linked list.
  • Traversal: repeatedly move to the next node.
  • Insertion: create node + adjust links.
  • Searching: compare each node until found or NULL.

03 — Advantages & Disadvantages

Know the wording that works well in theory answers.

✅ Advantages

  1. Dynamic size — can grow or shrink at runtime.
  2. Easy insertion and deletion — links are adjusted instead of shifting elements.
  3. No continuous memory requirement — nodes need not be adjacent.
  4. Memory allocated when needed — useful when size changes.

❌ Disadvantages

  1. Extra memory is needed for pointer/reference fields.
  2. No random access — nodes are accessed sequentially.
  3. Searching is slower because traversal may be required.
  4. Reverse traversal is difficult in a singly linked list.
  5. More complex than arrays to implement.

Array vs Linked List

ISC 2025
ASCII + traversal
Print the sum of the ASCII values of the lowercase alphabets present in the linked list.

🧾 Algorithm

  1. Initialize sum = 0.
  2. Set temp to the head/input Cell node.
  3. While temp is not NULL, check whether temp.m is lowercase.
  4. If yes, add its ASCII value to sum.
  5. Move temp to temp.right.
  6. After traversal, print sum.

💻 Java

void lowercase(Cell str) {
    int sum = 0;
    while (str != null) {
        if (str.m >= 'a' && str.m <= 'z')
            sum += (int) str.m;
        str = str.right;
    }
    System.out.println(
      "Sum of ASCII values of lowercase alphabets: " + sum);
}
ISC 2025 Specimen
SEARCH
Find a number in an existing linked list and display whether it is found.

🧾 Algorithm

  1. Start with temp = str.
  2. Repeat until temp is NULL.
  3. If temp.n == b, mark found and stop.
  4. Otherwise move to temp.link.
  5. If the loop ends without finding b, display “not found”.

💻 Java

void FindNode(Node str, int b) {
    Node temp = str;
    boolean found = false;

    while (temp != null) {
        if (temp.n == b) {
            found = true;
            break;
        }
        temp = temp.link;
    }

    if (found)
        System.out.println(b + " is found in the linked list.");
    else
        System.out.println(b + " is not found in the linked list.");
}
ISC 2023
INSERT AT END
Add a node at the end of an existing linked list.

🧾 Algorithm

  1. Create a new node temp.
  2. Set temp.sal ← ss and temp.next ← NULL.
  3. If ptr is NULL, set ptr ← temp and stop.
  4. Set t ← ptr.
  5. Move t forward while t.next ≠ NULL.
  6. Set t.next ← temp and stop.

💻 Java

void addNode(Node ptr, double ss) {
    Node temp = new Node();
    temp.sal = ss;
    temp.next = null;

    if (ptr == null)
        ptr = temp;
    else {
        Node t = ptr;
        while (t.next != null)
            t = t.next;
        t.next = temp;
    }
}
ISC 2020
INSERT AT BEGINNING
Insert a new node at the beginning of an existing linked list.

🧾 Algorithm

  1. Create a new node temp.
  2. Set temp.num ← n.
  3. Set temp.next ← startPtr.
  4. Set startPtr ← temp.
  5. The new node is now the first node.

💻 Java

void InsertNode(Node startPtr, int n) {
    Node temp = new Node();
    temp.num = n;
    temp.next = startPtr;
    startPtr = temp;
}
ISC 2019
SUM EVEN NODES
Find and display the sum of even integers from an existing linked list.

🧾 Algorithm

  1. Set temp = str and sum = 0.
  2. While temp is not NULL, test temp.num % 2 == 0.
  3. If true, add temp.num to sum.
  4. Move temp to temp.next.
  5. Display sum.

💻 Java

void SumEvenNode(Node str) {
    Node t = str;
    int s = 0;

    while (t != null) {
        if (t.num % 2 == 0)
            s = s + t.num;
        t = t.next;
    }

    System.out.println("Sum of even numbers = " + s);
}

SEARCH
Search for a number from an existing linked list.

🧾 Algorithm

  1. Set temp = str.
  2. Set flag = 0.
  3. While temp is not NULL, compare temp.n with b.
  4. If equal, set flag = 1 and exit loop.
  5. Otherwise move temp to temp.link.
  6. Display found/not found according to flag.

void FindNode(Node str, int b) {
    Node t = str;
    int f = 0;

    while (t != null) {
        if (t.n == b) {
            f = 1;
            break;

        t = t.link;

    if (f == 1)

}
ISC 2017
COUNT ODD NODES
Count the nodes that contain only odd integers and return the count.

🧾 Algorithm

  1. Set temp = startPtr and count = 0.
  2. While temp is not NULL, test temp.num % 2 != 0.
  3. If true, increment count.
  4. Move temp to temp.next.
  5. Return count.

💻 Java

int CountOdd(Node startPtr) {
    Node t = startPtr;
    int c = 0;

    while (t != null) {
        if (t.num % 2 != 0)
            c++;
        t = t.next;
    }
    return c;
}
ISC 2016
STRING SEARCH
Search for a given name in the linked list.

🧾 Algorithm

  1. Start with temp = start.
  2. Traverse until temp becomes NULL.
  3. If temp.name equals the given value, return true.
  4. Otherwise move to temp.next.
  5. If traversal finishes, return false.

💻 Java

boolean searchName(Node start, String v) {
    Node temp = start;

    while (temp != null) {
        if (temp.name.equalsIgnoreCase(v))
            return true;
        temp = temp.next;
    }
    return false;
}
Theory Essentials
REVISION

📌 Definitions

Linked list: a linear data structure whose elements are stored in nodes that need not occupy continuous memory.

Node: stores data and a link/reference to the next node.

🚀 Applications

  • Stacks and queues
  • Dynamic memory allocation
  • Undo/Redo operations
  • Playlist management
  • Browser history
  • Graph representation
Types of linked lists

Singly linked list — each node points to the next node. Doubly linked list — nodes point to both next and previous nodes. Circular linked list — the last node points back to the first.

Exam formula: traversal
temp = head;
while (temp != null) {
    // process temp
    temp = temp.next;
}
