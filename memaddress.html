Given: $B = 2500$, $W = 2$, $L_r = -5, U_r = 15$, $L_c = 10, U_c = 20$
Columns ($C$): $20 - 10 + 1 = 11$
Formula: $\text{Addr} = B + W \times [C(I - L_r) + (J - L_c)]$
Calculation: $2500 + 2 \times [11(10 - (-5)) + (15 - 10)] = 2500 + 2 \times [11(15) + 5] = 2500 + 2 \times 170 = 2840$
Given: $B = 1025, W = 4, L_r = -6, U_r = 10, L_c = 4, U_c = 15$
Rows ($R$): $10 - (-6) + 1 = 17$
Formula: $\text{Addr} = B + W \times [R(J - L_c) + (I - L_r)]$
Calculation: $1025 + 4 \times [17(8 - 4) + (4 - (-6))] = 1025 + 4 \times [17(4) + 10] = 1025 + 4 \times 78 = 1337$
Given: Dimensions $10 \times 15$ ($L_r=0, L_c=0, C=15$), $W=2$, $\text{Addr}(\text{MAT}[1][2]) = 2215$
Find Base ($B$): $\text{Offset}_1 = 15(1 - 0) + (2 - 0) = 17 \implies 2215 = B + 2 \times 17 \implies B = 2215 - 34 = 2181$
Find MAT[3][7]: $\text{Offset}_2 = 15(3 - 0) + (7 - 0) = 45 + 7 = 52 \implies \text{Addr} = 2181 + 2 \times 52 = 2285$
Given: $B=2140, W=2, L_r=-2, U_r=7, L_c=2, U_c=10, C = 10 - 2 + 1 = 9$
Calculation: $\text{Offset} = 9(5 - (-2)) + (6 - 2) = 9(7) + 4 = 63 + 4 = 67$
Address: $2140 + 2 \times 67 = 2140 + 134 = 2274$
Given: $10 \times 20$ ($R=10, C=20$), $W=2$, $\text{Addr}(\text{B}[2][1]) = 2140$
Find Base ($B$): $\text{Offset}_1 = 10(1 - 0) + (2 - 0) = 12 \implies 2140 = B + 2 \times 12 \implies B = 2116$
Find B[5][4]: $\text{Offset}_2 = 10(4 - 0) + (5 - 0) = 40 + 5 = 45 \implies \text{Addr} = 2116 + 2 \times 45 = 2206$
Given: $B=1430, W=4, L_r=-4, U_r=6, L_c=3, U_c=8, C = 8 - 3 + 1 = 6$
Calculation: $\text{Offset} = 6(3 - (-4)) + (6 - 3) = 6(7) + 3 = 42 + 3 = 45$
Address: $1430 + 4 \times 45 = 1430 + 180 = 1610$
Setup: $\text{Addr}(1,1) = B + 4[m(1-0) + (1-0)] = 1500 \implies B + 4(m+1) = 1500$
Setup 2: $\text{Addr}(4,5) = B + 4[m(5-0) + (4-0)] = 1608 \implies B + 4(5m+4) = 1608$
Subtract equations: $4(5m + 4 - m - 1) = 108 \implies 4(4m + 3) = 108 \implies 4m + 3 = 27 \implies 4m = 24 \implies m = 6$
Given: $B=1400, W=8, C=10$
Calculation: $\text{Offset} = 10(10 - 0) + (7 - 0) = 100 + 7 = 107$
Address: $1400 + 8 \times 107 = 1400 + 856 = 2256$
