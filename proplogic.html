1.1 – 1.2

Foundations

Before we can reason with symbols, we need to agree on what counts as a statement worth reasoning about.

DEFINITION — PROPOSITION

A declarative statement that is either true or false, but never both and never anything else. Questions, commands and exclamations are not propositions — they carry no truth value.

Is a proposition: "The month of January is very cold." · "Misha likes fruits."
Is not a proposition: "Good afternoon!" · "What are you eating?"

Simple vs. compound

A simple proposition is one atomic statement. Join two or more of them with a connective — "and", "or", "if...then" — and you get a compound proposition.

Simple
"Planet Mars is named after the Roman god of war."
Compound
"Mercury is the smallest planet in the solar system and it has no moon."

Truth values & truth tables

The truth or falsity of a proposition is its truth value — written as T/F or 1/0. A truth table lists every possible combination of input values against the resulting output. With n variables, there are 2ⁿ rows to fill.

Variables1234
Rows (2ⁿ)24816

Two routes lead to the same conclusion about a proposition: the truth table method (exhaustive, mechanical) and the algebraic method (rewriting using known laws).

Converse, inverse, contrapositive

For a conditional a → b, the antecedent is a, the consequent is b. Swap or negate them and you get three related conditionals:

NameFormRule
Converseb → aInterchange antecedent and consequent
Inversea' → b'Negate antecedent and consequent
Contrapositiveb' → a'Converse of the inverse
p = "MADAM reads the same from both sides", q = "It is a palindrome" — p → q
Converse: q → p — "If it is a palindrome then MADAM reads the same from both sides."
Inverse: p' → q' — "If MADAM does not read the same from both sides then it is not a palindrome."
Contrapositive: q' → p' — "If it is not a palindrome then MADAM does not read the same from both sides."

WFF, premise, syllogism

Well-Formed Formula
A propositional form built by valid rules: every atomic formula is a WFF, and if A, B are WFFs, so are ~A, (A∧B), (A∨B), (A→B), (A↔B).
Premise
A conditional statement used to establish a conclusion.
Syllogism
The logical process of deriving a conclusion from given premises.
1.7 – 1.8

Equivalence laws

Two statements are logically equivalent when they share the same truth value across every combination of variables. Eleven laws cover almost everything you'll ever need to simplify with.

LawExpression
Properties of 0a∨0 = a  ·  a∧0 = 0
Properties of 1a∨1 = 1  ·  a∧1 = a
Involution(a')' = a
Idempotenta∨a = a  ·  a∧a = a
Complementaritya∨a' = 1  ·  a∧a' = 0
Commutativea∨b = b∨a  ·  a∧b = b∧a
Associative(a∨b)∨c = a∨(b∨c)  ·  (a∧b)∧c = a∧(b∧c)
Distributivea∧(b∨c) = (a∧b)∨(a∧c)  ·  a∨(b∧c) = (a∨b)∧(a∨c)
De Morgan's(a∧b)' = a'∨b'  ·  (a∨b)' = a'∧b'
Conditional eliminationa→b = a'∨b
Biconditional eliminationa↔b = (a→b)∧(b→a)

Tautology, contradiction, contingency

Tautology
True for every combination of its variables — the final column is all 1s.
Contradiction
False for every combination — the final column is all 0s.
Contingency
Neither — the final column mixes 0s and 1s.
  • Every tautology is valid, and every valid proposition is a tautology.
  • Every tautology is satisfiable, but not every satisfiable proposition is a tautology.
  • Every contingency is satisfiable, but not vice versa.
  • Every contradiction is unsatisfiable, and every unsatisfiable proposition is a contradiction.

03 With p: "Jitendra Kumar is a computer teacher", q: "Rahul is a student" — write in symbolic form: "Neither Jitendra Kumar is a computer teacher nor Rahul is a student."

~p . ~q — negate both, then join with "and", since "neither...nor" rules out both possibilities at once.

04 Write the converse, inverse and contrapositive of: "If it rains, then you will not play."

Converse — If you will not play then it will rain.
Inverse — If it doesn't rain then you will play.
Contrapositive — If you will play then it will not rain.
